📌 A projektről

A STYLEUP egy ruházati webshop, amelynek célja egy modern, felhasználóbarát és reszponzív online áruház létrehozása.

A weboldalon a látogatók ruházati termékeket tekinthetnek meg, böngészhetnek a kínálatban, és egyszerűen eligazodhatnak az áruház különböző oldalai között.

📅 Projekt célja

A projekt célja a HTML, CSS, Bootstrap, JavaScript, JSON és Node.js technológiák gyakorlati alkalmazása egy valósághű webshop elkészítésén keresztül.

A munka során fontos szempont a csapatmunka, a feladatok megfelelő elosztása, a tervezés és a programozási ismeretek fejlesztése.
